## 2. 三种测试类型:何时用哪种

| 类型 | 注解 | 启动内容 | 速度 | 用途 |
|---|---|---|---|---|
| **切片测试** | `@WebMvcTest(BookController.class)` | 仅 Controller + Web 层 | ⚡ 快(< 1s) | Controller 请求/响应 + HTTP 状态码 + JSON 字段 |
| **业务单测** | `@ExtendWith(MockitoExtension.class)`(无 Spring) | 仅被测类 + Mock 依赖 | ⚡⚡ 最快(< 100ms) | Service 业务逻辑、参数归一化、边界值 |
| **集成测试** | `@SpringBootTest` + H2 | 整个 Spring 上下文 + 真实 DB | 🐢 慢(5–10s) | Mapper SQL、跨组件端到端 |

**默认优先级**:**业务单测 > 切片测试 > 集成测试**。能跑单测就别起 Spring。

## 3. 业务单测(Service 层)— Mockito 风格

### 3.1 模板

```java
package com.tmt.TMLibrary.service.impl;

import com.tmt.TMLibrary.common.Result.PageResult;
import com.tmt.TMLibrary.dto.BookSearchRequest;
import com.tmt.TMLibrary.entity.Book;
import com.tmt.TMLibrary.exception.BusinessException;
import com.tmt.TMLibrary.mapper.BookMapper;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

import java.math.BigDecimal;
import java.time.LocalDate;
import java.util.List;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;
import static org.mockito.ArgumentMatchers.any;
import static org.mockito.ArgumentMatchers.eq;
import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)         // 1. 启用 Mockito(不要用 @SpringBootTest!)
@DisplayName("BookServiceImpl 业务逻辑测试")
class BookServiceImplTest {

    @Mock                                       // 2. Mock Mapper,不连真实 DB
    private BookMapper bookMapper;

    @InjectMocks                                // 3. 自动注入 Mock 构造器
    private BookServiceImpl bookService;

    @Test
    @DisplayName("空 query 返回全量")
    void search_emptyQuery_returnsAll() {
        // given
        BookSearchRequest req = new BookSearchRequest();
        when(bookMapper.countBySearch(any())).thenReturn(2);
        when(bookMapper.selectListBySearch(any(), eq(0), eq(10)))
            .thenReturn(List.of(new Book(), new Book()));

        // when
        PageResult<Book> result = bookService.search(req);

        // then
        assertThat(result.getTotal()).isEqualTo(2);
        assertThat(result.getData()).hasSize(2);
        // 验证 page/size 兜底
        assertThat(req.getPage()).isEqualTo(1);
        assertThat(req.getSize()).isEqualTo(10);
    }

    @Test
    @DisplayName("page=0 兜底为 1")
    void search_pageZero_fallbackToOne() {
        BookSearchRequest req = new BookSearchRequest();
        req.setPage(0);
        req.setSize(20);
        when(bookMapper.countBySearch(any())).thenReturn(0);
        when(bookMapper.selectListBySearch(any(), eq(0), eq(20)))
            .thenReturn(List.of());

        bookService.search(req);

        // 关键:offset 用了兜底后的 page=1
        verify(bookMapper).selectListBySearch(any(), eq(0), eq(20));
    }

    @Test
    @DisplayName("minPrice=-1 兜底为 null,不参与 WHERE")
    void search_negativePrice_becomeNull() {
        BookSearchRequest req = new BookSearchRequest();
        req.setMinPrice(new BigDecimal("-1"));
        when(bookMapper.countBySearch(any())).thenReturn(0);
        when(bookMapper.selectListBySearch(any(), anyInt(), anyInt()))
            .thenReturn(List.of());

        bookService.search(req);

        assertThat(req.getMinPrice()).isNull();   // 归一化后应为 null
    }

    @Test
    @DisplayName("size=10000 clamp 到 100(防 DoS)")
    void search_hugeSize_clampedTo100() {
        BookSearchRequest req = new BookSearchRequest();
        req.setSize(10000);
        when(bookMapper.countBySearch(any())).thenReturn(0);
        when(bookMapper.selectListBySearch(any(), anyInt(), eq(100)))
            .thenReturn(List.of());

        bookService.search(req);

        verify(bookMapper).selectListBySearch(any(), anyInt(), eq(100));
    }

    @Test
    @DisplayName("getById 找不到抛 BusinessException(NOT_FOUND)")
    void getById_notFound_throwsBusinessException() {
        when(bookMapper.selectBookById(999)).thenReturn(null);

        assertThatThrownBy(() -> bookService.getById(999))
            .isInstanceOf(BusinessException.class)
            .hasMessageContaining("999");
    }
}
```

### 3.2 Mockito 速查

| 需求 | 写法 |
|---|---|
| Mock 一个对象 | `@Mock BookMapper bookMapper;` |
| 自动注入 Mock | `@InjectMocks BookServiceImpl service;` |
| 设置返回值 | `when(mapper.foo()).thenReturn(x);` |
| 设置抛异常 | `when(mapper.foo()).thenThrow(new SQLException());` |
| 任意参数 | `any()` / `anyInt()` / `anyString()` / `eq(5)` |
| 验证调用 | `verify(mapper).foo(5);` |
| 验证调用次数 | `verify(mapper, times(2)).foo();` |
| 验证从未调用 | `verify(mapper, never()).foo();` |
| 不关心 stub 的多余调用 | `@Mock(strictness = Mock.Strictness.LENIENT)` |

## 4. 切片测试(Controller 层)— `@WebMvcTest` + `MockMvc`

### 4.1 模板

```java
package com.tmt.TMLibrary.controller;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.tmt.TMLibrary.common.Result.PageResult;
import com.tmt.TMLibrary.entity.Book;
import com.tmt.TMLibrary.exception.BusinessException;
import com.tmt.TMLibrary.common.Result.ResultCode;
import com.tmt.TMLibrary.service.BookService;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.WebMvcTest;
import org.springframework.boot.test.mock.mockito.MockBean;
import org.springframework.test.web.servlet.MockMvc;

import java.util.List;

import static org.mockito.ArgumentMatchers.anyInt;
import static org.mockito.Mockito.when;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.*;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.*;

@WebMvcTest(BookController.class)               // 1. 只加载 Web 层,Service 用 @MockBean
@DisplayName("BookController HTTP 测试")
class BookControllerTest {

    @Autowired
    private MockMvc mockMvc;                    // 2. 模拟 HTTP 客户端

    @Autowired
    private ObjectMapper objectMapper;           // 3. JSON 序列化

    @MockBean                                   // 4. 替换真实 Service Bean
    private BookService bookService;

    @Test
    @DisplayName("GET /api/books?title=Java 返回 200 + Result 包结构")
    void search_returnsResultEnvelope() throws Exception {
        Book b = new Book();
        b.setId(1); b.setTitle("Effective Java");
        when(bookService.search(any())).thenReturn(new PageResult<>(1L, List.of(b)));

        mockMvc.perform(get("/api/books").param("title", "Java"))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.code").value(200))
            .andExpect(jsonPath("$.msg").value("成功"))
            .andExpect(jsonPath("$.data.total").value(1))
            .andExpect(jsonPath("$.data.data[0].title").value("Effective Java"));
    }

    @Test
    @DisplayName("GET /api/books/{id} 找不到返回 404 + NOT_FOUND")
    void getById_notFound_returns404() throws Exception {
        when(bookService.getById(anyInt()))
            .thenThrow(new BusinessException(ResultCode.NOT_FOUND, "图书不存在, id=999"));

        mockMvc.perform(get("/api/books/display").param("id", "999"))
            .andExpect(status().isOk())   // 业务异常也是 200 + code=404
            .andExpect(jsonPath("$.code").value(404))
            .andExpect(jsonPath("$.msg").value(org.hamcrest.Matchers.containsString("999")));
    }

    @Test
    @DisplayName("POST /api/books/created 缺 title 返回 400 + 校验消息")
    void create_missingTitle_returns400() throws Exception {
        String json = "{\"author\":\"x\",\"isbn\":\"1234567890\",\"price\":10.00,\"stockQuantity\":1,\"publishedDate\":\"2024-01-01\"}";
        mockMvc.perform(post("/api/books/created")
                .contentType("application/json")
                .content(json))
            .andExpect(status().isOk())   // @Valid 失败也是 200 + code=400
            .andExpect(jsonPath("$.code").value(400))
            .andExpect(jsonPath("$.msg").value(org.hamcrest.Matchers.containsString("title")));
    }
}
```

### 4.2 MockMvc 速查

| 需求 | 写法 |
|---|---|
| GET 请求 | `get("/api/books").param("k", "v")` |
| POST JSON | `post("/api/books/created").contentType(APPLICATION_JSON).content(json)` |
| 断言状态码 | `.andExpect(status().isOk())` / `.is4xxClientError()` |
| 断言 JSON 字段 | `.andExpect(jsonPath("$.code").value(200))` |
| 断言 JSON 含子串 | `.andExpect(jsonPath("$.msg").value(containsString("err")))` |
| 断言 header | `.andExpect(header().string("Content-Type", "application/json"))` |

## 5. 集成测试(Mapper 层)— `@SpringBootTest` + H2

### 5.1 测试配置 `src/test/resources/application.yml`

```yaml
spring:
  datasource:
    url: jdbc:h2:mem:testdb;MODE=MySQL;DB_CLOSE_DELAY=-1
    driver-class-name: org.h2.Driver
    username: sa
    password: ""
  sql:
    init:
      mode: always                          # 启动时执行 schema.sql
      schema-locations: classpath:db/schema.sql
      data-locations: classpath:testdata/books-1000.json

mybatis:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.tmt.TMLibrary.entity

logging:
  level:
    com.tmt.TMLibrary.mapper: DEBUG         # 让 SQL 打到控制台(测试用)
```

### 5.2 集成测试模板(`*IT.java` 命名,Maven Failsafe 默认识别)

```java
package com.tmt.TMLibrary.mapper;

import com.tmt.TMLibrary.entity.Book;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.mybatis.spring.boot.test.autoconfigure.MybatisTest;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.jdbc.AutoConfigureTestDatabase;

import java.util.List;

import static org.assertj.core.api.Assertions.assertThat;

/**
 * @brief BookMapper 集成测试 — 跑真 SQL,用 H2 内存库
 *        用 @MybatisTest 而不是 @SpringBootTest,只加载 MyBatis 相关 Bean(更快)
 */
@MybatisTest                                // 1. 等价于 @SpringBootTest + 只加载 MyBatis 层
@AutoConfigureTestDatabase                  // 2. 替换 DataSource 为 H2
@DisplayName("BookMapper 集成测试")
class BookMapperIT {

    @Autowired
    private BookMapper bookMapper;

    @Test
    @DisplayName("selectList 全量返回")
    void selectList_returnsAll() {
        List<Book> books = bookMapper.selectList(0, 10);
        assertThat(books).isNotEmpty();   // schema.sql + books-1000.json 已加载
    }

    @Test
    @DisplayName("selectListByTitle LIKE 转义:title=% 应查不出(通配符不被吞)")
    void selectListByTitle_escapesWildcards() {
        // 假如 % 拼成 LIKE '%%%',会查全表 — 这里验证不会
        List<Book> books = bookMapper.selectListByTitle("%", 0, 10);
        // 真实数据库里不应该有 title='%' 的书
        assertThat(books).isEmpty();
    }

    @Test
    @DisplayName("countBySearch 空 query 返回总条数")
    void countBySearch_emptyQuery_returnsTotal() {
        // 这里需要先调一次 selectList 拿到 total,或者通过其他途径
        // 简化:断言 > 0
        int total = bookMapper.countBooks();
        assertThat(total).isGreaterThan(0);
    }
}
```

### 5.3 H2 的 MySQL 兼容模式坑

H2 默认 SQL 方言跟 MySQL 有差异,常见踩坑:

| 问题 | H2 默认行为 | 解决方案 |
|---|---|---|
| `BIGINT AUTO_INCREMENT` | 支持 | 直接用 |
| `VARCHAR` 大小写 | 不敏感 | OK |
| `DATE` 字面量 | 不接受 `'2024-01-01'` 格式 | URL 加 `MODE=MySQL` |
| `DATETIME` vs `TIMESTAMP` | 行为略有差异 | URL 加 `MODE=MySQL` |
| `ON UPDATE CURRENT_TIMESTAMP` | 不支持 | 测试表里手动设值,不用触发器 |
| `ENGINE=InnoDB` 等尾缀 | 不识别 | 写 SQL 时去掉 |

**实战方案**:`schema.sql` 单独写一份 `src/test/resources/db/schema-h2.sql`,把 `ENGINE=InnoDB DEFAULT CHARSET=utf8mb4` 等 MySQL 专属语法去掉。

## 6. 异常测试 — 验证 GlobalExceptionHandler

```java
package com.tmt.TMLibrary.exception;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.tmt.TMLibrary.common.Result.ResultCode;
import com.tmt.TMLibrary.controller.BookController;
import com.tmt.TMLibrary.exception.BusinessException;
import com.tmt.TMLibrary.service.BookService;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.WebMvcTest;
import org.springframework.boot.test.mock.mockito.MockBean;
import org.springframework.test.web.servlet.MockMvc;

import java.time.format.DateTimeParseException;

import static org.mockito.ArgumentMatchers.anyInt;
import static org.mockito.Mockito.when;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.jsonPath;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

@WebMvcTest(BookController.class)
class GlobalExceptionHandlerTest {

    @Autowired MockMvc mockMvc;
    @MockBean BookService bookService;

    @Test
    void businessException_returns404Envelope() throws Exception {
        when(bookService.getById(anyInt()))
            .thenThrow(new BusinessException(ResultCode.NOT_FOUND, "图书不存在, id=5"));

        mockMvc.perform(get("/api/books/display").param("id", "5"))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.code").value(404));
    }

    @Test
    void dateTimeParseException_returns400Envelope() throws Exception {
        // 触发 DateTimeParseException — LocalDate.parse("not-a-date")
        when(bookService.searchByPublishedDate(any(), anyInt(), anyInt()))
            .thenThrow(new DateTimeParseException("not-a-date", "not-a-date", 0));

        mockMvc.perform(get("/api/books/search/publishedDate/not-a-date"))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.code").value(400))
            .andExpect(jsonPath("$.msg").value(org.hamcrest.Matchers.containsString("not-a-date")));
    }
}
```

## 8. 测试纪律

1. **每个测试方法一个 `assertThat` 块验证一件事** — 不要堆 5 个断言,失败时定位更准
2. **测试名 = 场景描述** — `search_emptyQuery_returnsAll` 比 `test1` 好
3. **`@DisplayName` 写中文** — 失败时一眼看懂,不必去翻代码
4. **Mock 优先,真实 DB 慎用** — 99% 的测试用 Mockito 即可
5. **集成测试要可重入** — 不依赖执行顺序,不依赖外部资源
6. **完成 ≠ 验证**(参见 `docs/开发踩坑记录.md` #6)— 写完测试必须 `./mvnw test` 看绿才能勾 checkbox
